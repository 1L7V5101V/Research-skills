# 科研符号与参数管理（Research Modeling）

在科研推导、仿真和写作过程中，维持符号记号与物理参数的绝对一致性。核心目标是：消除符号二义性、统一量纲单位、溯源材料参数，并在确定下来的瞬间将其固化到文档中。

## 文件结构

在项目根目录中按需维护以下核心文件（仅在确定第一个条目时创建，不提前建空文件）：

```
/
├── SYMBOLS.md        ← 数学符号、物理量定义与张量记号表（防符号冲突）
├── PARAMETERS.md     ← 物理常数、材料本构参数、实验参数及来源
└── docs/
└── adr/          ← 关键建模路线与理论简化决策记录（ADR）
```


## 协作过程中的准则

### 1. 符号与量纲审查（防冲突）
- **查重预警**：当引入新公式或新变量时，立刻对照 `SYMBOLS.md`。如果出现符号复用（例如用 $E$ 同时表示杨氏模量和电场强度），立即指出并建议区分（如改为 $Y$ 与 $\mathbf{E}$）。
- **量纲与张量阶数锁定**：每个符号必须明确其**国际单位制（SI）单位**和**张量阶数**（标量、矢量 $\mathbf{v}$、二阶张量 $\boldsymbol{\sigma}$、四阶张量 $\mathbb{C}$）。

### 2. 参数溯源与代码交叉验证
- **参数必须有出处**：写入 `PARAMETERS.md` 的数值必须标明是物理常数、文献引用还是实验实测值。
- **代码一致性检查**：在编写或检查仿真/计算代码时，核对代码中的变量名、硬编码数值及单位换算是否与 `SYMBOLS.md` 和 `PARAMETERS.md` 严格一致，发现不一致立即提示。

### 3. 随定随记
- 一旦某个符号命名或材料参数确定下来，**立即**更新对应的 Markdown 文件，不攒到最后统一整理。
- 严格区分**符号定义**（只写符号、名称、量纲、记号约定，放 `SYMBOLS.md`）和**具体数值**（具体材质的数值、温度条件、参考文献，放 `PARAMETERS.md`）。

### 4. 审慎记录模型决策（ADR）
仅当某个建模路线或理论简化同时满足以下三点时，才提议在 `docs/adr/` 下记录决策：
1. **推翻成本高**：一旦选定，后续公式推导或仿真代码架构都要围绕它展开。
2. **需要上下文解释**：审稿人或未来的自己看到这里会问“当初为什么选 A 路线而不选 B 路线？”
3. **经过真实权衡**：在计算效率、解析可解性与模型精度之间做过明确的取舍。
